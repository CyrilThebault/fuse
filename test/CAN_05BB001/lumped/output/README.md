# Output directory

This directory stores the output files generated by FUSE.

The directory is included in the repository so that the example
applications have a valid output location after cloning the repository.
Git does not track empty directories, so this file is provided to ensure
that the directory is created when the repository is checked out.

Model output files are written to this directory according to the
`output_dir` entry in the control file. Depending on the simulation mode,
FUSE generates one or more NetCDF files, including:

- `*_runs.nc` — simulated model output time series.
- `*_para.nc` — parameter values used during the simulation or generated
  during calibration.

See the **Model outputs** documentation for a description of these files.
